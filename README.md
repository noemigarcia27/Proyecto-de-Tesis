# Proyecto de Tesis

**Tema:** Análisis de una estrategia CPPI con multiplicador adaptativo dependiente de la volatilidad bajo un modelo de volatilidad estocástica.

## Descripción
Registro y control semanal de avances teóricos, modelación matemática y código de simulación para el proyecto de tesis.

## Modelos y Enfoque Metodológico
- **Renta Variable:** Modelación del IPC mediante procesos estocásticos continuos.
- **Renta Fija:** Tasas de CETES calibradas a la dinámica local.
- **Propuesta:** Multiplicador adaptativo dependiente de la volatilidad instantánea para mitigar el riesgo de *cash-out*.
